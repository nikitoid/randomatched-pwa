# Запуск и развертывание вашего приложения AI Studio

Здесь содержится все необходимое для локального запуска вашего приложения.

Посмотреть ваше приложение в AI Studio: https://ai.studio/apps/drive/1gYFMwYRnoU050O0-6-heg5xnsBSRURlz

## Локальный запуск

**Предварительные требования:** Node.js

1. Установите зависимости:
   `npm install`
2. Установите `GEMINI_API_KEY` в [.env.local](.env.local) на ваш API ключ Gemini
3. Запустите приложение:
   `npm run dev`
